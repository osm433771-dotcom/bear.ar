바나나 고양이 AR (학교 실습용)

[들어 있는 파일]
- index.html            : 웹 AR 페이지 (이 파일을 링크로 열면 됨)
- kitten.glb            : 안드로이드(WebXR)와 3D 미리보기용 모델. 동작 Idle / Wave / Jump / Run
- kitten.usdz           : 아이폰(Quick Look)용 모델. 손 흔들기 → 점프 → 뛰어다니기가 이어져 계속 반복
- model-viewer.min.js   : 구글 model-viewer 4.1.0 (같이 넣어 두어서 인터넷 CDN이 필요 없음)
- preview.png           : 미리보기 그림
- source/build_kitten.py  : 모델을 만드는 블렌더 파이썬 스크립트
- source/kitten.blend     : 블렌더 파일

[크기]
- 키 약 16cm, 실제 크기로 고정
- 뛰어다니기: 책상 위 가로 약 15cm × 세로 약 9cm 안에서 8자 모양으로 돌고 제자리로 돌아옴

[사용 방법]
- 아이폰: Safari에서 열고 초록 버튼 → Apple AR 화면(Quick Look)에서 책상을 비추면 올라감.
  Quick Look에서는 버튼을 쓸 수 없어서 세 동작이 차례로 반복됨.
- 안드로이드: Chrome에서 열고 초록 버튼 → 책상을 비추면 올라가고, 화면 아래 버튼으로 동작을 고를 수 있음.
- 컴퓨터: AR은 안 되고 3D로만 보임.

[주의]
- 휴대폰 AR은 https 주소에서만 동작함. 파일을 더블클릭해서 열면 AR이 안 됨.
  확인한 뒤 GitHub Pages 같은 곳에 폴더째 올리면 됨.
- 컴퓨터에서 미리 보려면 이 폴더에서:  python3 -m http.server  → 브라우저에서 http://localhost:8000

[모델 다시 만들기]
  pip install bpy==5.3.0   (Python 3.13)
  python source/build_kitten.py 출력폴더
